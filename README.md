# BotaOy — Баян Сұлу 

Добро пожаловать в **BotaOy** — интерактивное игровое веб-приложение, созданное для обучения и развлечения пользователей. Проект сочетает в себе элементы геймификации, магазин предметов и систему личных достижений.

---

## Основные возможности

* **Мини-игры:** Широкий выбор активностей, включая Memory, викторины, математические квесты и классическую «Змейку».
* **Система прогресса:** Уровни, статистика и отслеживание достижений.
* **Игровой магазин:** Кейсы разной степени редкости (Common, Rare, Epic, Legendary) и кастомизация профиля.
* **Интерактивный интерфейс:** Современный дизайн, плавная анимация и адаптивность под мобильные устройства.
* **Мультиязычность:** Поддержка казахского языка и возможность переключения локализации.

---

## 🛠 Стек технологий

* **Frontend:** HTML5, CSS3 (использование Flexbox, Grid, CSS Variables).
* **Логика:** JavaScript (ES6+), манипуляции с DOM.
* **Дизайн:** Анимированные элементы, SVG-иконки, Google Fonts (Nunito, Fredoka One).
